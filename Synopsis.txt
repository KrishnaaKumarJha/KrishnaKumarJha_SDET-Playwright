-------------------------------------------------------------DAY 1--------------------------------------------------------------------------------------------
-Worked with variables (let, var) to store values
    Syntax: let a = 10;
-Performed basic mathematical operations (+, -, *, /, %)
    Syntax: a + b;
-Learned comparison and logical operators (==, ===, >, <)
    Syntax: 5 === "5";
-Practiced string operations (length, uppercase, substring)
    Syntax: str.toUpperCase();
-Understood block scope vs global scope (let vs var)
    Syntax: { let x = 10; var y = 20; }
-Learned arrays and mixed data types
    Syntax: let arr = [1, "Hello", true];
-Used loops (for, while) to iterate
    Syntax: for(let i = 0; i < arr.length; i++)
-Applied conditional statements (if-else)
    Syntax: if(i > j) {}
-------------------------------------------------------------DAY 2--------------------------------------------------------------------------------------------
-Used template literals for dynamic strings
    Syntax: Hello ${name};
-Learned functions and arrow functions
    Syntax: const sum = (a, b) => a + b;
-Practiced array methods (find, filter, map, forEach)
    Syntax: arr.filter(x => x > 2);
-Chained array methods
    Syntax: arr.filter().map().forEach();
-Generated random numbers using Math.random()
    Syntax: Math.random();
-Used Math functions (floor, ceil)
    Syntax: Math.floor(3.7);
-Performed type conversion (Number, String, parseInt, parseFloat)
    Syntax: Number("5");
-Worked with array operations (push, pop, shift, unshift)
    Syntax: arr.push("item");
-Checked elements using indexOf() and includes()
    Syntax: arr.includes("apple");
-Studied reduce() for summing values and processing arrays
    Syntax: arr.reduce((acc, val) => acc + val, 0);
-Used reduce() to count frequency of elements in an array
    Syntax: acc[item] = (acc[item] || 0) + 1;
-Practiced DOM manipulation to access and update HTML elements
    Syntax: document.getElementById("id");
-------------------------------------------------------------DAY 3--------------------------------------------------------------------------------------------
-Practiced array methods like forEach(), map(), filter(), and reduce() for iteration, transformation, and data processing.
-Combined multiple array methods and used reduce() for advanced tasks like aggregation and flattening arrays.
-------------------------------------------------------------DAY 4--------------------------------------------------------------------------------------------
-Synchronous vs Asynchronous: Learned difference between blocking (sync) and non-blocking (async) execution using setTimeout() and setInterval().
    Syntax: setTimeout(() => {}, 2000);
-Promises: Used Promises to handle asynchronous operations with .then() and .catch() for success and error handling.
    Syntax: new Promise((resolve, reject) => {})
-Async Handling: Practiced delayed execution and repeated tasks using timers and Promise-based data handling.
    Syntax: promise.then(data => console.log(data));
-Practiced asynchronous JavaScript using fetch() to retrieve data from multiple public APIs and handle responses using .then() and .catch().
    Syntax: fetch(url).then(res => res.json());
-------------------------------------------------------------DAY 5--------------------------------------------------------------------------------------------
-Learned async/await for handling asynchronous operations and executing promises in a sequential manner.
-Applied async/await with fetch() to retrieve and process API data using map(), filter(), find(), and reduce().
-Learned Object-Oriented Programming (OOP) to organize code using classes and objects.
-Understood access modifiers to control data visibility (public and private using #).
-Encapsulation: Protecting data by restricting direct access and using methods.
-Inheritance: Reusing properties and methods from one class to another.
-Polymorphism: Using the same method name with different behaviors.
-Abstraction: Hiding complex implementation and showing only essential features.
